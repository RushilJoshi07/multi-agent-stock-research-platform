# 22214c6 — Number checker: a structured claim must equal its stored value exactly
2026-11-11 · 3 files changed, 42 insertions(+), 3 deletions(-)
Hole 1, claim side: validate_claims no longer uses the flat 0.01 tolerance. A structured claim
cites a stored source, so its value must equal that value (math.isclose, rel_tol 1e-9, abs_tol 0)
and a rounded claim like 0.77 against a stored 0.771 is rejected. That closes p = 0.045 passing
against a stored 0.054. Rounding belongs only to prose, where the text keeps its decimals; the
scan still used the old tolerance at this commit, pending that rule.
