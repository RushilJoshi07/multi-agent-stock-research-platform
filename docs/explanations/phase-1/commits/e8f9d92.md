# e8f9d92 — Number checker: '.65' reads as 0.65 and '1,234' as one number
2026-11-11 · 3 files changed, 56 insertions(+), 3 deletions(-)
Number parsing in the narrative scan: ".65" now reads as 0.65 (it read as 65) and "1,234" as one
number (it read as 1 and 234). Thousands grouping only counts when every group has exactly three
digits and no digit follows, so lists like "1,2,3" and bad groupings like "1,2345" still split.
Commas are stripped before float(). Known edge: an unspaced list of three-digit numbers
("100,200") reads as 100200; it fails closed (flagged), never passes a wrong number.
