# dc543d1 — Phase 1 step P1: DATABASE_URL guard against the old project's Postgres
2026-10-28 · 5 files changed, 832 insertions(+), 2 deletions(-)
Added the old-database guard in two layers: a URL check in make_engine before any engine exists
(port 5432 only for host `postgres`, no strategy_research* names), and a check on every new
connection that the server has no strategy_research* database. Plus a whole-repo AST scan that
fails if anything other than core/db.py opens a Postgres connection. Also ships the approved plan.
Why: the restore is next, and connecting to the old database by mistake is the one error that
can't be undone. Non-obvious: two code reviews found libpq bypasses (host lists, hostaddr, dsn,
?dbname=) that a host+port check alone missed; the connect-time check covers what no URL shows.
